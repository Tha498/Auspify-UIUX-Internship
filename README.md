# Auspify Technologies – UI/UX Internship Tasks 1–4

This package contains four original, beginner-friendly UI/UX project concepts based on the supplied task-list PDF.

## Projects
1. **Task 1 – Mobile App Wireframe:** StudyBuddy low-fidelity mobile layout, navigation structure, user flow and usability notes.
2. **Task 2 – Landing Page UI:** LearnFlow responsive product landing page with hero section, feature cards, navigation and calls to action.
3. **Task 3 – Mobile App Prototype:** StudyBuddy interactive prototype with Home, Tasks, Add Task, Calendar and Profile screens. Add tasks and mark tasks complete.
4. **Task 4 – Dashboard UI/UX:** Responsive admin dashboard with sidebar, KPI cards, traffic chart, traffic-source visualization, searchable user table and section navigation.

## How to run
- Extract the ZIP file.
- Open each task folder.
- Double-click `index.html` or open it in Chrome, Edge or Firefox.
- No build tools or dependencies are required.

## Design and UX decisions
- Consistent typography, spacing, rounded cards and blue/navy visual language.
- Responsive layouts for desktop and mobile breakpoints.
- Clear visual hierarchy and navigation labels.
- Semantic HTML, form labels, visible interaction feedback and accessible contrast intent.
- Sample names and metrics are fictional demo content, not real company data.

## Important submission notes
- Review and personalize the projects before submitting. You should be able to explain the design decisions and demonstrate the interactions yourself.
- Task 1 is a browser-based low-fidelity wireframe, not a Figma source file.
- Tasks 2–4 are coded browser prototypes. If your coordinator specifically requires editable Figma files, recreate/import the layouts in your own Figma workspace.
- Capture screenshots of each task in your browser and add them to the corresponding folder before final submission.
- Create a GitHub repository under your own account and upload the extracted project folders if a repository link is requested.
- The task brief says to complete any 4 of the 6 tasks; these four folders cover Tasks 1–4.
